# 2026 年 12 月 POC 记录

12 月只记录 ChainPay-Lab POC 的实现、测试和复盘。主实现放在 [`poc/chainpay-lab/`](../../poc/chainpay-lab/README.md)，本目录保存月度命令、输出和决策记录。

## 目录约定

```text
practice/2026-12/
└── README.md                 # 每周命令、输出、决策和下月 backlog

poc/chainpay-lab/
└── agent-payments/
    ├── fixtures/             # 固定订单、账本、差错池和事件
    ├── tools/                # 白名单只读工具
    ├── schemas/              # 输入输出 schema
    ├── evals/                # 成功和失败路径评估
    └── observability/        # run、耗时和失败记录
```

## 完成标准

- 入口可以在本地固定数据上直接运行，或 README 明确写出缺少的工具链。
- 报告覆盖匹配、金额不一致和单边记录。
- 测试覆盖空数据、重复事件、乱序事件、超时、错误输出和权限拒绝。
- 记录 run id、工具调用、耗时和失败原因。
- 月末演示不连接网络、数据库或真实支付系统。

## 与 11 月的衔接

11 月的 Java、Go 练习和共用语法入口继续保留在原目录。12 月只把需要的实现能力用于 POC，不新增语言基础练习任务。
