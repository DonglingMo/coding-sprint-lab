# coding-sprint-lab
一个长期维护的个人编程实验室：每日手写代码、多语言练习、月度 POC、自动化测试与学习复盘。

当前项目周期标识为 `coding-sprint-lab-2026-11`，对应 2026 年 11 月迭代。项目元数据见 [project.yml](project.yml)，本月计划见 [docs/monthly-plan-2026-11.md](docs/monthly-plan-2026-11.md)，完整使用指南见 [docs/usage-guide-2026-11.html](docs/usage-guide-2026-11.html)。

后续月度迭代沿用 `coding-sprint-lab-YYYY-MM` 的项目标识、`docs/monthly-plan-YYYY-MM.md` 的计划文件名和 `docs/usage-guide-YYYY-MM.html` 的指南文件名。开始新周期时，更新 `project.yml` 中的 `cycle`、`project_id`、`plan` 和 `guide`，完成周期后创建对应的 Git 标签 `cycle-YYYY-MM`。
